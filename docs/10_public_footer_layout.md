# Public footer layout repair

The shared public footer is a three-column responsive grid on desktop:
1. Full Mod Alpha Ventures LLP corporate lockup, brand description and social links.
2. Platform navigation.
3. Help navigation.

A separate full-width legal row contains copyright, historical-performance disclaimer, Privacy and Terms. At tablet/mobile widths the brand occupies the first row and Platform/Help become two columns; legal content stacks beneath them. Footer remains in normal document flow and is not fixed.
