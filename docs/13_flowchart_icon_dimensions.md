# Flowchart icon sizing — reference match

The pictograms and their surrounding tiles are both scaled to match the supplied visual reference, not just swapped glyphs.

Desktop target dimensions:
- Market data icon tiles: 52×52 px; pictograms 30×30 px.
- AI analysis tag icon wells: 30×30 px; pictograms 27×27 px; tags have a consistent 58 px minimum height.
- Selected-date target: 32×32 px well; 30×30 px pictogram.
- Notification bell tile: 62×62 px; 34×34 px pictogram.
- Notification channel tiles: 58×58 px; 31×31 px pictograms.
- Bottom benefit icon circles: 58×58 px; 32×32 px pictograms.
- Step number badges: 40×40 px.

The sizes scale down at laptop and mobile breakpoints to preserve the five-stage composition without clipping.
