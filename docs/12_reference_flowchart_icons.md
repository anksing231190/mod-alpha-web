# Flowchart iconography

The How Mod Alpha Works explainer now uses inline SVG pictograms instead of font-dependent Unicode glyphs. Icon choices mirror the supplied reference: NAV trend chart, yellow volatility bolt, teal calendar, purple database, purple trend/bar/clock/brain analysis symbols, teal target marker, yellow notification bell, cyan email envelope, cyan chat bubble, and matching benefit icons. Icons inherit the reference colour palette and retain rounded-square icon tiles. SVGs are local inline markup, so no external icon font or network dependency is required.
