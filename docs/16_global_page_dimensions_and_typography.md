# Global page dimensions and typography — v16

## What changed
- Standardized authenticated user/admin content to a shared 1,450px maximum content frame, centered inside the workspace.
- Standardized public subpages to the same maximum content width; landing hero and How It Works keep their own visual composition inside that frame.
- Standardized gutters with fluid desktop/tablet/mobile spacing.
- Replaced very small scattered text sizes with a consistent hierarchy: 14px body, 13px controls, 12px supporting labels, 11px captions, 16px card headings, and 27–34px page headings.
- Increased table, fund-card, KPI, settings, pricing and AI chat typography to readable sizes.
- Kept responsive breakpoints so grids and controls adapt rather than shrinking text on smaller screens.

## Reference alignment
The desktop page frame is based on the supplied Mod Alpha 1536px-wide reference compositions. The How Mod Alpha Works illustration retains its dedicated screenshot-matched layout and animated connector treatment. Component-specific layouts remain distinct; only their shared frame, spacing and type scale are normalized.
