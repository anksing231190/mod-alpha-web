# How Mod Alpha Works — flowing stage connectors

Reference: `how-mod-alpha-works-flow-reference.png`

The public explainer should communicate a connected left-to-right process, not isolated cards with static arrows.

Desktop flow:
1. Market data collection
2. Mod Alpha AI analysis engine
3. Monthly recommended date insight
4. Subscriber notification
5. User reviews the reminder and invests independently through their provider

Each connector now has an animated gradient beam, a travelling cyan energy particle, a glowing arrow tip and a subtle receiving-stage halo. Connectors activate in sequence with the stage reveal and continue flowing while the explainer is visible. The animation respects `prefers-reduced-motion`; on narrow screens the layout stacks vertically and connector arrows are hidden rather than rendered incorrectly.
